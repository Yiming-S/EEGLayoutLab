## 本轮数据边界

项目是长期研究记录，队列回执用于跟踪任务，两者分别保存。项目只接收服务器验证后的完成结果，不接收浏览器自行填写的科学输出。保存项目会复制不可变的结果快照并记录 SHA-256，不改写原计算结果。标题、备注、归属和共享权限独立于科学输入与缓存身份。

首版使用项目访问凭据，持有者可跨浏览器恢复项目；所有者可以生成和撤销只读凭据。显示姓名用于项目说明，不作为身份认证。凭据只存哈希于服务端，浏览器通过请求头发送；科学交付包不包含访问凭据。后续集中账号系统可在此基础上接入。

项目目录位于队列目录的 `projects/`。它不受结束任务回执上限影响，并纳入停机备份与恢复。访问凭据恢复文件与包含私有项目的服务备份应由项目所有者和服务器维护者保管。

## 科学结果对照

原始材料归档于 `artifacts/productization/2026-11-13/`。本轮基线包括科学源码、配置、模型 SHA-256，原生布局的完整前向场，以及单源、多源的原始输入数组与科学输出。每阶段重新检查文件身份并执行相同的单源、多源科学工作流；逐数组、逐字段比较，不放宽数值容差。

原生布局的复核使用上一轮已经实际求解并验证的 `128 × 4352` 完整矩阵与相同科学代码、输入；如这些文件未变，本轮不重复昂贵的原生求解。报告明确区分复核与新求解。耗时及来源说明不属于数值相等比较；随机种子、坐标、质量指标和科学输出保留在比较范围内。

本轮所有会写入结果的检查使用项目 `artifacts/` 下的隔离工作区，不使用日常科学结果目录。已有未提交的重构改动与 Mac 外壳移除保持原状。

## 阶段一验收

390 项网页测试、45 项备份恢复测试、8 项真实 HTTP 检查和 7 项浏览器流程通过，类型、静态检查与生产构建通过。实际存档覆盖布局、63 电极编辑结果及完整信号结果。项目恢复、只读分享与撤销通过。真实单源／多源存档在元数据修改和重启读取后字节与 SHA 不变。浏览器发现的表单提交类型和选择框可访问标签问题在验收前修复；失败现场与正式报告分别保留。汇总为 `stage1-acceptance.json`。

## 阶段二验收

426 项网页测试及 9 项真实浏览器流程通过，类型、静态检查与生产构建通过。自定义比较要求完整保存；归档信号在阻断旧信号与旧记录接口时仍可播放、切换通道并下载，完整下载 JSON 与原结果严格相等。中英文恢复、只读导航和凭据不进入文档返回链接已实测。共同阈值的字面设置与旧解析器行为一致性问题已修复；科学对照再次通过。汇总为 `stage2-acceptance.json`。

## 阶段三验收

433 项网页测试和 15 项真实浏览器流程通过，类型、静态检查与生产构建通过。管理者、只读合作者、中文界面均完成交付下载；包内四条布局／编辑／信号记录的原始文本与存档逐字节一致，全部文件与清单校验通过。下载说明复用已校验数据；取消准备和切换项目均取消实际请求且没有过期下载。真实单源／多源导出、原始指标和比较要求保留通过独立检查。汇总为 `stage3-acceptance.json`。

## 阶段四验收

最终主应用的 442 项网页测试、460 项 Python 测试和 190 个 Python 子测试通过；另有 3 项 Python 测试跳过、2 项原生计算测试排除。类型检查、静态检查和生产构建通过。最终浏览器验收包括 16 项产品与交付流程、7 项项目基础流程、10 项完整使用流程，以及 20 项三维视图检查，均通过。实际断网恢复与排队取消已检查；未增加新的 FEM 求解。

请求编号、任务关联、固定类别运行指标和有大小及保留期限的请求日志已接入。运维接口只允许直接本机访问，并提供只读命令行探针。实测低磁盘门槛时，新计算及项目修改返回 `503` 和 `Retry-After`，已有项目、交付包、取消及精确缓存回放仍可用。7 项真实低资源检查、4 项开发模式检查和 30 项原始 HTTP 压缩检查通过。内存门槛只检查当前 Node 进程；服务器的科学工作进程峰值与容量仍须在目标平台实测。

更新后的锁文件完成实际 `npm ci`；完整与生产依赖审计均为零已知受影响条目。相关应用和科学回归使用最终安装的依赖执行，未改 Python 依赖或科学参数。[依赖记录](security.md)区分当前与历史审计。

另建无冻结数据、科学结果、运行环境和构建产物的 419 文件源码副本，保留 7 个网页模型文件。快速层通过 435 项网页测试（7 项数据层跳过）和 458 项 Python 测试（7 项数据／原生层排除，190 个子测试通过），类型和静态检查通过。网页依赖通过明确记录的验收用链接复用，Python 从副本源码加载；这不等于另一次独立安装。

实际暂停、排空并停止本轮验收服务后，执行备份预览、备份、新目录恢复与完整校验。524 个文件、139,877,500 字节全部与清单一致。恢复后的应用代码读取 13 个项目、21 条有效记录，布局／编辑／信号三类原始快照逐字节一致，原所有者凭据仍能访问。恢复目录保留维护状态；完整数据包、运行环境、依赖安装、构建与服务启动仍须按交接说明完成，未将文件恢复表述为新服务器已运行。

四阶段独立科学对照均通过：95 个科学源码／配置／模型／数据文件未变；每阶段实际单源、多源计算输入数组及科学输出精确一致。已合格的 `128 × 4352` 原生前向场及坐标复核一致；本轮没有重新求解。最终交付包的完整快照文本、数值、来源和质量检查与保存记录一致。汇总为 `final-scientific-acceptance.json` 和 `stage4-acceptance.json`。

本轮材料按开工日期集中保存在 `artifacts/productization/2026-11-13/`，完成时间跨至 2026-11-14。私有项目、访问文件及备份仅用于本地验收，受 Git 忽略规则保护，不作为公开仓库或 Releases 内容。验收端口 4394、4395、4396 均已停止；原有工作应用未被停止。
