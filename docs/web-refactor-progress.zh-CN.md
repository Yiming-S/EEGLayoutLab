## 阶段 1

独立布局数据类型、跨语言请求样例和信号仿真校验器已建立。服务模块的循环导入已消除；原接口与缓存规范化语义保留。

四类计算共用任务客户端，连接状态与后台任务状态分开。查询采用有上限的退避重试；提交失败不自动重复提交。会话失效、任务丢失和接口版本不兼容停止自动轮询，保留最后确认的任务状态，并提供显式恢复入口。

增加 API 版本响应头和稳定错误码，旧错误文本和接口路径继续兼容。模块依赖检查防止浏览器导入服务代码以及服务间循环导入。

完整测试发现两类旧测试假设需要更新：直接查找内联 `fetch` 的断言，以及不能处理类型再导出的场景测试装载器。调整测试装载方式后，249 项网页测试全部通过。没有删除原行为断言。

## 阶段 2

四类计算共用执行许可、Python 进程通信和记录存储。执行器统一处理输出、超时、取消和进程组退出；工作流保留各自的线程数、输入校验、结果校验和科学身份。只有进程退出且结果保存完成后才释放许可。

维护状态写入队列文件。暂停同时阻止新计算和排队派发，保留缓存读取、取消和完成状态同步。回归测试覆盖暂停与异步准备、缓存查询、启动之间的竞争，以及重启、存储失败和未确认退出的进程。复核发现并修复了明确返回忙碌时残留启动标记的问题，任务现在恢复原排队位置。

记录存储包住原目录结构，统一检查路径、原子替换和落盘同步。设计与信号服务共用独立科学上下文，不再互相读取服务内部属性。使用重构前的设计上下文代码核对当前实现，相同根目录、请求和输入得到完全一致的身份及缓存键。

新增隔离验证工作区工具，默认只预览。实际验证复制了当前源码、21 个数据清单文件和本机科学环境；复制后的 Python、SimNIBS、NumPy、SciPy 均从隔离目录加载。该目录仅用于本机验证，不是跨平台运行环境安装包。真实接口测试写入 `artifacts/verification/phase2-isolated/`，不写入日常结果目录。

第一轮完整网页测试发现编辑器测试仍引用旧目录属性。改为通过存储接口读取真实缓存后，284 项测试全部通过。真实接口验证通过 11 个页面、402 条基础记录、半径布局、编辑准备、63 电极编辑副本、坐标评价、旧版信号仿真、原生 FEM、新版单源和多源仿真。8 次计算均通过结果校验及相同输入缓存回放；原生 FEM 约 104 秒，新版单源约 106 秒，多源约 4 秒。

## 阶段 3

首页、布局设计和结果库拆为独立控制器与工作区；两个历史结果页移入功能目录。五个路由入口只导出对应功能。控制器负责 URL、AR、草稿和请求生命周期，页面负责呈现。

三维代码拆为资源加载、资源释放、电极层、源标记层和场景控制；旧入口继续再导出。资源加载失败和场景初始化失败均有清理测试。结果页拆出数据投影、统一播放状态和双侧接收对照，两侧使用同一时间和场强标尺。

完整网页测试 313 项通过。类型、代码检查和生产构建通过。20 项三维浏览器检查覆盖鼠标、触摸、显示层切换、全屏和手机布局。10 项完整用户流程检查覆盖：

- 中英文总览、记录库与草稿控件；URL、筛选及 AR 往返保留。
- 刷新草稿不自动提交计算；手动重复提交读取相同计算结果。
- 中断真实 GET 请求后显示恢复入口，显式重连恢复布局。
- 另存 63 电极编辑结果并保留原 64 电极记录；对比页恢复两条记录及 AR。
- 新的 DK40 单源实验完成，播放、通道选择和 JSON 下载可用。
- 取消真实未缓存任务后状态为 cancelled，结果为空。

浏览器验收修复了编辑记录的中英混合指标文案，以及缺少图标声明导致的 favicon.ico 请求失败。旧三维测试也按当前控件名称、默认语言、参考层默认隐藏状态及真实布局标识更新等待条件。最终完整流程没有页面运行错误、非预期控制台错误或 HTTP 失败；主动断网产生的错误单独记录。

生产构建仍提示部分压缩资源超过 500 kB。信号页本次测得 22 个 JavaScript 请求，传输 1,842,111 字节。两幅接收视图在滚入视口后开始绘制，均显示 64 个电位值；独立截图已核对。视口外停止绘制，但仍提前下载模型；本阶段观察到约 12 MB 的皮层文件重复传输。该重复下载已在随后一轮通过共享版本化字节缓存修复，见[性能修复与测量](web-performance.zh-CN.md)。文件拆分本身没有被记为首屏体积下降。

## 阶段 4

开发与生产宿主适配已集中。生产服务保持监听本机；显式公共来源和可信代理地址配置可启用代理访问，并校验 Host、HTTPS 来源和单一客户端地址。HTTPS 会话使用 Secure Cookie。本机 HTTP 测试和独立复核通过，最终域名、TLS、代理与访问范围仍需目标服务器验证。

无模型数据的独立副本通过 306 项网页检查，明确跳过 7 项数据检查；Python 通过 424 项测试及 190 项子检查，排除 5 项数据和 2 项原生测试。副本始终没有 results/、data/external/ 或 .runtime/。GitHub 快速检查工作流已加入；远程执行结果保存在仓库的 Actions 记录中。

完整本地 Python 回归通过 426 项测试及 190 项子检查；3 项需显式启用的真实库测试跳过，2 项原生单元测试排除。真实原生 FEM 和信号任务另由第二阶段接口集成完成。备份及隔离工作区工具的 57 项针对性检查通过。

真实维护演练完成暂停、排空、停止、重启后保留暂停，以及显式恢复。备份包含 392 个文件、55,794,260 字节；恢复到新目录后，21 个基础输入重新复制并校验，405 条布局记录、1 条编辑记录、3 条信号回执和布局导出可读。队列文件与会话密钥和快照逐字节一致。恢复检查没有重新安装原生运行环境，也没有在恢复目录进行新计算。

发布和恢复工具区分宿主源码目录、科学目录和队列目录。清单记录实际源码、数据和运行环境身份；源代码变动、活跃写入者、未知启动状态、清单不符或覆盖已有目标均会阻止操作。真实备份保留在本项目 artifacts 下，不作为公开发布材料。
