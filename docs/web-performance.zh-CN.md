# 网页加载与计算性能

本文保存第一轮模型共享下载修复与性能测量，材料位于 `artifacts/performance/2026-11-13/`。该轮使用已有隔离结果，没有提交新 FEM 任务。随后已完成共享前向计算、运行环境检查复用、无损压缩与按需加载，并运行原生科学对照；当前结果见[三阶段优化验收](performance-optimization-progress.zh-CN.md)。两轮测试日期均为 2026-11-13（本机时区）。

## 已完成：模型共享加载

`webapp/viewer/asset-cache.ts` 按资源 URL 和 SHA-256 合并正在进行的下载，下载成功后保留通过校验的字节。信号页两侧查看器以及同页重新展开的查看器复用这些字节。缓存上限为 32 MiB、四个已完成条目，按最近使用顺序淘汰。

每个场景仍有独立的位置、法线、索引数组和几何体。关闭、旋转或修改一侧不会改动另一侧的数据；最后一个使用者取消时才终止尚未完成的下载。失败条目从内存移除，下次请求绕过浏览器中的旧响应，支持下载失败和校验失败后的恢复。

小型模型索引每次重新验证。二进制请求附带内容 SHA-256，模型更新后使用新的请求地址。完整页面刷新会重建内存缓存，是否再次传输取决于浏览器的 HTTP 缓存；不能把同页复用等同于跨刷新永久保存。

## 第一轮浏览器对照结果

| 操作 | 修改前模型传输量 | 修改后模型传输量 | 修改前双视图可用时间 | 修改后双视图可用时间 |
| --- | ---: | ---: | ---: | ---: |
| 首次打开信号结果 | 25.70 MB | 13.66 MB | 28.57 秒 | 20.72 秒 |
| 同页折叠两侧查看器后重新展开 | 24.09 MB | 1.2 kB | 20.78 秒 | 4.50 秒 |
| 普通刷新页面 | 24.09 MB | 12.04 MB | 24.68 秒 | 16.69 秒 |

传输量采用浏览器 Resource Timing 的 `transferSize`，包含响应头；MB 和 kB 为十进制单位。首次模型传输减少 46.9%，本次双视图可用时间减少 27.5%。同页重新展开仅重新验证四次小型索引，头皮与皮层二进制请求均为零。普通刷新在本测试浏览器中仍传输一份皮层文件，已从修改前的两份降为一份。

这三种情况下，两侧均绘制完整皮层与 64 个电位值，独立通道选择及共用色标通过，未出现页面错误、HTTP 错误或新的计算提交。原始报告和截图分别位于 `baseline/`、`shared/`；`shared-debug/` 保留了最初把索引重新验证也视为失败的测试断言记录，正式验收已改为区分索引与二进制请求。

## 第一轮验证方式

- 全部 Node 测试：330 项通过，其中新增 17 项缓存测试。
- 类型检查、静态检查和生产构建通过。
- 三维查看器浏览器回归：20 项通过，覆盖鼠标旋转、头皮/脑视图、布局切换、图层显隐、全屏、手机布局和触摸操作，页面运行错误为零。
- 75 个科学源码、配置与模型文件的 SHA-256 与重构基线完全一致。
- 浏览器对照使用相同的已缓存单源实验、英文界面、1440 × 1100 视口、Chrome 软件渲染、10 Mbps 带宽和 40 ms 延迟。首次加载使用全新浏览器上下文；同页重挂载和普通刷新在同一上下文内完成。
- 可用时间定义为：从导航或重新展开开始，到两侧三维画布均进入视口、绘制首帧并显示 64 个电位值。该时间包含结果查询、脚本加载和渲染，不是单独的模型下载时间。

浏览器脚本验证两侧独立选择不同通道、相同电位色标、实际布局身份、精确结果回放和无新计算提交，并记录请求次数、Resource Timing、CDP 传输量和截图。冷启动、重新挂载和刷新各一次；耗时是本机同条件对照，不是多轮统计或服务器性能承诺。

从 `webapp/` 目录运行（服务必须指向隔离科学目录，示例端口 4391）：

```sh
EEG_TEST_URL=http://127.0.0.1:4391 \
EEG_BROWSER_EXECUTABLE='/Applications/Google Chrome.app/Contents/MacOS/Google Chrome' \
EEG_BENCHMARK_LABEL=current \
EEG_SIGNAL_FIXTURE=/absolute/path/to/qa-signal-result.json \
EEG_QA_OUTPUT="$PWD/../artifacts/qa-candidate/model-loading" \
node scripts/check-model-loading-browser.mjs --expect-shared --expect-deferred
```

`EEG_SIGNAL_FIXTURE` 必须是目标服务中已有、身份匹配的完整单源结果 JSON。缺少对应缓存时测试失败，不会自动提交计算。其他开发环境可替换浏览器路径、结果文件和项目内的输出目录。

## 第一轮测量中代价较小的部分

405 条记录的列表热查询为 3–4 毫秒，现有缓存有效。400 点信号的显示投影在 Node/V8 中平均耗时 1.4–1.7 毫秒，并且界面已经缓存投影结果；不需要按每帧重新计算来修复。JSON 解析约 9.4 毫秒、序列化约 10.6 毫秒，慢网络下应先减少传输量。

原始计时和调用路径见 `artifacts/performance/2026-11-13/measurements.json` 与 `findings.zh-CN.md`；只读测量脚本为同目录的 `audit.mjs`。压缩尺寸见 `compression-measurements.json`。这些本地测试材料不纳入 GitHub 源码仓库。
