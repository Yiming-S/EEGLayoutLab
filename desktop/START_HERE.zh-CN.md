# EEG Layout Lab · Mac 桌面版

适用于 Apple Silicon（M 系列芯片）Mac，macOS 14 或更新版本。

## 安装

1. 打开 [Google Drive 下载文件夹](https://drive.google.com/drive/folders/1Ry-neU-oySVoToIt07eFfBnemKrnewmK?usp=sharing)，下载 `.dmg` 桌面安装包。
2. ZIP：解压后，将 **EEG Layout Lab.app** 拖到“应用程序”。
   DMG：打开镜像，将 App 拖到旁边的“应用程序”快捷方式。
3. 双击打开 **EEG Layout Lab**。
4. 首次打开时等待内置环境与模型数据准备完成，之后会自动显示界面。

无需安装 Node.js、Python 或 Conda，无需单独复制模型数据。以后直接从“应用程序”打开。

## 首次系统确认

当前为使用本地测试签名的版本，尚未使用 Developer ID 签名和 Apple 公证。
如果系统提示开发者无法验证，确认安装包来自维护者后，先尝试打开一次，再进入
“系统设置 → 隐私与安全性 → 仍要打开”，对这一个 App 进行确认。
如果提示文件损坏或恶意软件，先联系维护者检查安装包。

## 使用

- “结果库”：浏览已保存布局、查看指标和对比方案。
- “布局设计”：设定区域、编辑电极或导入坐标，再启动计算。
- “信号仿真”：设置脑源、波形和干扰，比较接收信号。
- 右上角：切换中文和英语。
- “文档”：查看操作指南和计算原理。
- 退出：按 **Command + Q**。关闭窗口后也可以从程序坞重新打开窗口。

新结果自动保存到本机。菜单中的数据文件夹和日志入口用于查看保存位置或反馈问题。
